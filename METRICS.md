# BindingMetrics metrics reference

The metrics reference is [`docs/metrics.md`](docs/metrics.md). It holds the function signatures, result keys, units, algorithm notes and command-line options of every metric, the score versus feature classification, the metric registry and the scorecard thresholds.

For installation, the command-line tools and the pipeline, see [`README.md`](README.md). The changes between versions are listed in [`CHANGELOG.md`](CHANGELOG.md).
